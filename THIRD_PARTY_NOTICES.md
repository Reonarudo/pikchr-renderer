The library's own TypeScript, tests and scripts are MIT licensed (see `LICENSE`). This
does not relicense the vendored engine.

## Pikchr

`vendor/pikchr/` contains the Pikchr diagram compiler by D. Richard Hipp, from
<https://pikchr.org/home>:

- `pikchr.c` — generated by `make pikchr.c` from `pikchr.y` at trunk check-in
  `a7f1c35bc0448daf15e2bafa36e510c1517534e6` (2026-04-03). Upstream no longer versions
  this file; it is committed here so the compiled source can be audited without Fossil.
  The generated file includes the Lemon parser template, which is in the public domain.
- `pikchr.cjs` — the same source compiled to WebAssembly by `scripts/build-wasm.sh` with
  Emscripten 6.0.9.
- `provenance.json` records the check-in, its date and the compiler; `SHA256SUMS` pins all
  three files and the test suite checks it.

Pikchr is distributed under the Zero-Clause BSD license (`licenses/PIKCHR-0BSD`).
